# Roadmap and Approval Gates

## Gate 1 — current delivery

Canonical tokens; dark/light infrastructure; 25 UI primitives and stories; reusable shell with desktop/mobile navigation; blocks for common states; one Overview example; AI rulebook and shared Markdown; registry/static publishing configuration. Runtime build approval remains pending because dependencies could not be installed in the creation environment.

## Gate 2 — after visual approval

Calibrate widths, typography and motion against the owner's live reference at known zoom. Approve the Overview, then create Account/Settings as the first standard page. Preserve the approved shell and tokens.

## Gate 3 — page templates

Login, List, Details and Form, with real composition examples and complete state stories. Add patterns based on those pages, not speculative filler components.

## Gate 4 — downstream consumers

Test a clean registry installation into a second project, lock a release, document migrations, and optionally ship a compiled package. Automate screenshot regression only after the owner accepts a baseline.
